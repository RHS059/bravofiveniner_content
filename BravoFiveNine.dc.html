How I work

Every pack starts from the same premise: the weapon should feel right before it looks right. Prefabs get proper classnames, handguards and rails are separate parts so attachments actually mount, magazines are their own base types, and the firing and reload animations get custom sound rather than borrowed engine stock.

The packs are deliberately built on shared foundations — B59 Attachments, BravoCore, SoundFX and BravoEFX. One set of dependencies, consistent behaviour across every weapon, and a lot less duplicated download for server owners running several of my mods at once.

Licences lean permissive on purpose. Most of the catalogue is Arma Public License No Derivatives with explicit written permission to use it as a dependency, restat it, retexture it, add attachments or change the sounds and redistribute those changes. Compatibility mods for WCS and RHS ship alongside the packs for the same reason — the point is that other people can build on this.
